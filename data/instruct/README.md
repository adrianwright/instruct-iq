# Synthetic instructional ingestion assets

This is offline canonical input for a single synthetic district, teacher, and
24-student grade-7 science class. No real learner data is present. `registry.json`
contains membership, item/skill coverage, raw responses (including explicit
missing submissions and absent observations), approval/effective history, and
normalized test-double batches. It deliberately contains no derived groups or
hand-maintained group counts.

Regenerate with `python data\instruct\generate.py --write`. Documents and registry
are deterministic; consistency tests compare every generated byte and validate
normalized contracts. Digests cover the UTF-8 evidence excerpt, without newline.
`test_double` provenance is truthful offline provenance, not connected proof.
Ingestion must create native resource IDs/revisions and recompute provenance from
actual stored content. Runtime policy/adapters must never import this generator
or load these files as a fallback.
